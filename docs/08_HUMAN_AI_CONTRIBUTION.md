## 2. AI 智能体辅助边界与具体执行工作

在本研究中，AI 科研与编程智能体始终在人类监督下承担**辅助调研、工程脚手架构建与自动化验证执行**工作：

- **文献检索与书目核验辅助**：检索近两年 RAG 不确定性检索与知识冲突解码相关顶会论文，核对 BibTeX 条目与公开会议录/arXiv 信息，交由人类作者最终确认采纳。
- **模块化代码与单元测试编写**：在人类确定的架构规范下编写 `src/` 核心算法模块、数据集适配器、独立可插拔竞品对比算子（`results/MileStone4_Competitor/reuse/operators/`）以及全套 CPU `unittest` 回归测试用例。
- **实验编排与遥测日志整理**：生成支持断点续跑、防 OOM 序列卸载与原子写盘的实验运行脚本，并编写纯数据驱动的图表绘制脚本与汇总脚本。
- **LaTeX 排版与文档规范化**：辅助完成中英文双语论文的 ACL/arXiv LaTeX 模板编排、表格尺寸微调与竞赛 8 项规范文档整理。

## 3. 学术诚信与严谨性声明

1. 本项目所有报告数字均 100% 源自真实运行并保存的 JSON 检查点日志（位于 `evidence/`），不存在任何捏造、篡改或主观外推数据。
2. 我们在论文与证据报告中如实披露了自我审计发现的所有负面结论与适用边界——包括 `WP8.1` 中 `V5 Proxy` 对纯缺失信息（`Q4`）的局限性以及 `WP8.2` 中无门控 JS 惩罚对多跳桥接证据的误伤现象。
